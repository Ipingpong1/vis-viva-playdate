# Vis-Viva (Playdate Game)

A level-based physics game about slingshotting around planets for the Playdate console.

## How to Install on Your Playdate

You can quickly install and play this game on your Playdate hardware or inside the Playdate Simulator.

### Option 1: Sideloading (Easiest for Hardware)
1. On this GitHub page, click the green **Code** button at the top right and select **Download ZIP**.
2. Extract the downloaded ZIP file on your computer.
3. Log into your [Playdate Account Sideload Page](https://play.date).
4. Drag and drop the `GravityGolf.pdx` folder directly into the web browser upload box.
5. On your Playdate, go to **Settings > Games** and select **Sideload** to download the game over Wi-Fi.

### Option 2: Data Disk Mode (USB Cable)
1. Download and extract the repository ZIP file.
2. Connect your Playdate to your computer via USB.
3. On your Playdate, go to **Settings > System > Data Disk**.
4. Open the Playdate drive on your computer, navigate to the `Games` folder, and drop the `GravityGolf.pdx` folder inside.
5. Eject the Playdate drive.

### Option 3: Playdate Simulator
1. Download and extract the repository ZIP file.
2. Open the **Playdate Simulator** app on your computer.
3. Go to **File > Open** (or double-click the `GravityGolf.pdx` folder) to launch the game.
